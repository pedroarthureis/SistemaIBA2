## 📚 Sobre o Projeto

O **Sistema de Gestão Acadêmica IBA** é uma aplicação web desenvolvida com o objetivo de centralizar e facilitar o gerenciamento das atividades acadêmicas e administrativas do **Instituto Bíblico de Anápolis (IBA)**.

A proposta surgiu a partir da necessidade de substituir processos manuais e informações dispersas por uma solução centralizada, permitindo o gerenciamento de alunos, professores, cursos, matérias, matrículas, notas e demais informações acadêmicas.

O sistema busca proporcionar maior organização, agilidade e confiabilidade no gerenciamento dos dados, reduzindo retrabalho e facilitando o acesso às informações pelos usuários.

---

## 🎯 Objetivos

### Objetivo Geral

Desenvolver um sistema web para auxiliar na gestão acadêmica e administrativa do Instituto Bíblico de Anápolis, centralizando informações e automatizando processos relacionados à vida acadêmica dos alunos.
